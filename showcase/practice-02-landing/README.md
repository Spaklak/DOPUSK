# Практика №2 · Лендинг стартапа

Лендинг знакомит аналитиков и команды с «Допуском». На примере оттока клиентов он показывает, как шлюз контролирует доступ ИИ к локальным данным. Целевое действие — заявка на тестирование.

Для локального просмотра скачайте репозиторий и откройте `landing/index.html` в браузере.
