# Лендинг «Допуска»

Одностраничный сайт для аналитиков и команд, которые работают с конфиденциальными данными. Схема на первом экране показывает место MCP-шлюза между агентом и локальной средой. Пример с оттоком клиентов объясняет, какой результат можно передать в облако.

## Локальный просмотр

Откройте `index.html` в браузере. Вариант для просмотра по HTTP из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory landing
```

Откройте [локальный сайт](http://127.0.0.1:8000/). Разметка, стили, сценарий, иллюстрации и шрифт Manrope поставляются вместе с сайтом.

## Подключение заявок

В начале [app.js](app.js) находится настройка `applicationFormUrl`. При пустом значении кнопки выводят рядом с собой сообщение «Приём заявок скоро откроется».

Опубликуйте Google Форму с доступом для участников по ссылке, скопируйте ссылку для заполнения и вставьте её между кавычками в `applicationFormUrl`. После обновления страницы обе кнопки откроют форму. При проверке отправьте тестовую заявку и найдите её во вкладке «Ответы» в Google Формах.

## GitHub Pages

Для публикации из папки `landing/` подготовлен [сценарий GitHub Actions](../.github/workflows/landing-pages.yml) с ручным запуском. Во время совместной публикации выберите GitHub Actions в настройках Pages и запустите сценарий из ветки `main`. После проверки опубликованного адреса его можно добавить в [карточку практики](../showcase/practice-02-landing/README.md).
