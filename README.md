# Допуск

### Ваш ИИ-помощник. Ваши данные. Ваши правила доступа.

**Допуск** — проект, который помогает использовать облачных ИИ-агентов при работе с конфиденциальными данными. Локальный MCP-шлюз контролирует, какие операции доступны агенту и какие результаты можно передать в облако.

## Как это работает

- **Данные остаются локально.** Вычисления выполняются в рабочей среде аналитика.
- **Доступ задаётся правилами.** Агент обращается к разрешённым инструментам и получает доступную структуру данных и агрегаты.
- **Результаты проходят проверку.** Перед отправкой в облако они проверяются по заданным правилам и при необходимости подтверждаются пользователем.

## Где пригодится

Аналитикам, Data Scientists и ML-инженерам, работающим с клиентскими, финансовыми и внутренними данными компаний: в финтехе, e-commerce, страховании и HR-tech.

> «Найди факторы оттока клиентов и обучи базовую модель».
>
> Агент помогает провести анализ, а исходная таблица остаётся локально. В облако уходят только разрешённые метрики и результаты.
